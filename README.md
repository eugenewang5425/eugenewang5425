## 👤 关于我 / About Me

我是一名**地理信息科学（GIS）**专业出身的开发者，主要研究**高分辨率遥感影像土地覆盖分类**，正把 GIS / 空间智能当作桥梁，转向 **3D 视觉、机器人感知与建图**方向。

> **🚩 当前主线**：GIS / 空间智能 → 计算机视觉 → 机器人感知与建图 → 机器人学习。

**🧠 技能 / Skills**：Python · PyTorch · 深度学习（CNN/Transformer/语义分割）· 遥感影像处理 · GIS/ArcGIS · 测绘 · Git
